## Câu hỏi
Repo zalo-miniapp hiện chỉ có tài liệu. Đã có một repo code Vue riêng (zalo-miniapp-vue). Gộp code vào repo này hay giữ hai repo?

## Phương án
| Phương án | Được gì | Mất gì |
|---|---|---|
| Gộp vào zalo-miniapp | Tài liệu, việc, code, test cùng một PR. CI kiểm được truy vết | Phải chuyển lịch sử code |
| Giữ hai repo | Không phải chuyển | Truy vết từ yêu cầu tới test phải đi qua hai repo, CI khó kiểm |

## Đề xuất
Gộp vào zalo-miniapp.
