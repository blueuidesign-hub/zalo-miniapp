## Câu hỏi
Code đang có ở zalo-miniapp-vue dùng Vue 3, Tailwind, Vite. Bộ giao diện ZaUI và các mẫu app chính thức của Zalo mà tôi tra được đều viết bằng React. Chưa xác nhận được Zalo có hỗ trợ Vue chính thức không. SK4 câu 7 sẽ trả lời phần kỹ thuật.

## Phương án
| Phương án | Được gì | Mất gì |
|---|---|---|
| Giữ Vue | Dùng lại code đã có, người làm đã quen | Tự viết thành phần giao diện. Ít mẫu, ít ví dụ chính thức để AI và dev dựa vào |
| Chuyển React | Dùng ZaUI và mẫu chính thức, nhiều ví dụ hơn | Bỏ code Vue hiện có, phải học lại nếu chưa quen |

## Đề xuất
Chưa đề xuất. Chờ SK4: nếu code Vue chạy ổn trong Zalo và gọi được zmp-sdk thì nghiêng về giữ Vue, vì code nghiệp vụ chưa nhiều thì chưa phải lý do để đổi.
