# Quy tắc nghiệp vụ

Quy tắc dùng chung cho nhiều yêu cầu: giá, đêm, lịch, quyền xem, căn tự nhập. Mỗi file một QT cấp 1, theo docs/process/templates/qt.md. Quy tắc được rút ra từ mục "Quy tắc nghiệp vụ phát hiện" của các file YC và từ tài liệu bối cảnh (DC1). **Chưa có quy tắc nào được chốt.**
