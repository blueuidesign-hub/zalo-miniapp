## Mục tiêu
Mỗi PR chạy GitHub Actions: build, test, và báo đỏ khi bản build quá 10 MB hay có file quá 3 MB (giới hạn của Zalo). Repo private gói Free có 2.000 phút Actions mỗi tháng.

## Ghi chú
Gói Free trên repo private chỉ báo đỏ, không chặn được nút gộp (QD5). Muốn chặn thì cần gói Pro hoặc repo public.
