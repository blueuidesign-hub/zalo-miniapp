## Câu hỏi cần trả lời
Hộp thoại hiện thế nào, từ chối rồi thì sao, token đổi ở server ra sao, người thử ngoài nhóm có lấy được số không.

## Ghi chú
Đổi token lấy số cần server giữ App Secret. Chưa có backend (SK5) thì chỉ thử tới bước nhận token và hộp thoại, ghi lại phần đổi token là chưa thử.
